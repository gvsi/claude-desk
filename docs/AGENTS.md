# The docs folder

These rules add to the root [AGENTS.md](../AGENTS.md) for this folder. They cover [the product proposal](product-proposal.md) and [the capability prediction](capability-prediction.md), which the prototype's About this prototype reading pages show.

- **Where the words are written.** The committed Markdown files are the source for the repository and the About this prototype reading pages. Propose changes through a pull request. A change to a safety sentence needs the review panel (root AGENTS.md) to check it against the kernel's implementation and tests before it merges.
- **Pull requests only.** Every edit goes through a pull request, never straight to `main`, however small. The root file's allowance for minor docs-only changes doesn't cover these files. Once the About this prototype reading pages are on `main`, that pull request is a design PR ("Design PRs" in the root AGENTS.md).
- **Before commit.** Run `make docs-check` and, once the reader's code is on `main`, `cd web && npx vitest run --project unit src/about`, which parses both files with the reader itself.
- **What the reader reads.** A `#` title, the byline line, `##` sections, paragraphs, one-level bulleted lists, tables, bold text, code spans, links, and the `[measured: …]` and `[owner: …]` placeholders. A figure goes where its marker sits on a line of its own: `<!-- figure: architecture -->`, `<!-- figure: tau3 -->` or `<!-- figure: readiness -->`. The one image is `![…](images/v1-architecture.svg)`, on the line right after the architecture marker, for readers of the repository; the page draws its own figure there. Nothing else: no raw HTML, no fenced code, no headings below `##`, no bare web or e-mail address (GitHub links one; write `[text](https://…)`), and links only to `https://` addresses or the other document's file name. The tools tests (`cd tools && uv run pytest -q`) catch the common breaks.
- **Quote marks.** Write straight `'` and `"`; the pages show them curly, with the common leading elisions (’til, ’em, rock ’n’ roll, ’90s) as apostrophes. Where the page would still pick the wrong mark, such as a quoted 'em dash', whose 'em reads as an elision, type the curly one yourself.
