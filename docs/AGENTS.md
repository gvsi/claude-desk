# The docs folder

These rules add to the root [AGENTS.md](../AGENTS.md) for this folder.

- [The product proposal](product-proposal.md) and [the capability prediction](capability-prediction.md) change only through a pull request, never straight to `main`, however small the edit. The root file's allowance for minor docs-only changes doesn't cover them.
- Once the prototype's About this prototype reading pages are live, they show these two files' text, so a pull request that changes either file is a design PR ("Design PRs" in the root AGENTS.md).
